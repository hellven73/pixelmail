# PixelMail

Internal messaging only. Sign up with a unique PixelMail username and password. Messages stay in private mailboxes on the dedicated Sydney Supabase project. The browser uses a public anon key; the registration edge function keeps its privileged key server-side.

Publish the main branch root using GitHub Pages. Sign-up is limited to 30 attempts per hour and 1,000 profiles. Maximum five files and 25 MiB combined per message. Save your password securely: email-based recovery and 2FA are not available. Scheduled sending is local-demo only. External email is not supported.
